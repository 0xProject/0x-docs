---

The 0x Solana Swap API finds the best price for a swap across Solana DEXs and returns the instructions that execute it. Your app puts them in a transaction, the user's wallet signs it, and you send it to Solana.

## Access and authentication

[Get an API key](https://dashboard.0x.org/create-account) from the 0x Dashboard, then send it in the `0x-api-key` header of every request. Call the API from your backend so that the key is not exposed in browser or mobile code.
