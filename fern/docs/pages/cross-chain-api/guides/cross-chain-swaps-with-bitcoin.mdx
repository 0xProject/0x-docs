## Steps to Cross Chain Swap Native BTC

You can use the `/quotes` and `/status` endpoints to move value in both directions:

- Buy BTC: sell a token on an EVM chain and receive native BTC at a Bitcoin address.
- Sell BTC: sell native BTC from a Bitcoin address and receive a token on another chain.

The examples use USDC on Base as the other side of the swap.

### 0. Prerequisites

Make sure you have:

- [0x API key](https://dashboard.0x.org/apps)
- A mainnet Bitcoin address. Use a P2WPKH address that starts with `bc1q` when you can.
- To buy BTC: a funded EVM wallet, set up as in [Get started](/cross-chain/cross-chain-api/guides/get-started).
- To sell BTC: BTC at your Bitcoin address in a confirmed UTXO. The amount must cover the sell amount and the miner fee.
- To sell BTC: a way to sign a PSBT and broadcast a raw Bitcoin transaction. The example below uses [bitcoinjs-lib](https://github.com/bitcoinjs/bitcoinjs-lib).

## Bitcoin values

Use these values in every Bitcoin request:

| Item | Value |
| --- | --- |
| Chain name | `bitcoin` |
| Chain ID | `999999999994` |
| Native BTC token | `bc1qqqqqqqqqqqqqqqqqqqqqqqqqqqqqqqqmql8k8` |
| Decimals | `8` |

Write BTC amounts as integers in base units, the same as EVM token amounts. The base unit of BTC is the satoshi. BTC has 8 decimals, so 1 BTC = 100,000,000 satoshis.

- `100000000` = 1 BTC
- `1000000` = 0.01 BTC

The native BTC token is a token id. Put it in `sellToken` or `buyToken` only. The API rejects it as `originAddress` or `destinationAddress`.

The API supports native BTC only.

<Accordion title="Supported Bitcoin address types">
The API accepts mainnet addresses of these types:

| Type | Starts with |
| --- | --- |
| P2PKH | `1` |
| P2SH | `3` |
| P2WPKH | `bc1q`, 42 characters |
| P2WSH | `bc1q`, 62 characters |
| P2TR | `bc1p` |

</Accordion>

## Buy BTC with a token on an EVM chain

### 1. Fetch a quote

Set `destinationChain` to `bitcoin` and `buyToken` to the native BTC token.

```typescript
const quotesParams = new URLSearchParams({
    originChain: 'base', // Base mainnet
    destinationChain: 'bitcoin', // Bitcoin mainnet
    sellToken: '0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913', // USDC on Base
    buyToken: 'bc1qqqqqqqqqqqqqqqqqqqqqqqqqqqqqqqqmql8k8', // native BTC
    sellAmount: '20000000', // 20 USDC (6 decimals)
    originAddress: '$USER_EVM_ADDRESS', // Base address that sells the USDC
    destinationAddress: '$USER_BITCOIN_ADDRESS', // Bitcoin address that receives the BTC
    sortQuotesBy: 'price',
    maxNumQuotes: '3',
});

const headers = {
    '0x-api-key': '[api-key]', // Get your live API key from the 0x Dashboard (https://dashboard.0x.org/apps)
};

const response = await fetch('https://api.0x.org/cross-chain/quotes?' + quotesParams.toString(), { headers });
const quoteResponse = await response.json();
```

`destinationAddress` is required. Without it, the API returns HTTP 400 `INPUT_INVALID` with the reason `Bitcoin destinationAddress is required`.

### 2. Set an allowance and send the transaction

The origin is an EVM chain, so you follow the EVM flow:

1. If `issues.allowance` is not `null`, approve the sell token for `allowanceTarget`.
2. Sign and send `transaction.details` from the quote you picked.

[Get started](/cross-chain/cross-chain-api/guides/get-started) shows both steps with viem.

### 3. Monitor the cross chain execution

Poll `/status` with the Base transaction hash and the `quoteId`.

```typescript
const statusParams = new URLSearchParams({
    originChain: 'base',
    originTxHash: txHash, // hash of the Base transaction from step 2
    quoteId: quoteResponse.quotes[0].quoteId,
});

const statusResponse = await fetch('https://api.0x.org/cross-chain/status?' + statusParams.toString(), { headers });

console.log(await statusResponse.json());
```

The BTC is at `destinationAddress` when `status` is `bridge_filled`.

## Sell BTC for a token on another chain

### 1. Fetch a quote

Set `originChain` to `bitcoin` and `sellToken` to the native BTC token.

```typescript
const quotesParams = new URLSearchParams({
    originChain: 'bitcoin', // Bitcoin mainnet
    destinationChain: 'base', // Base mainnet
    sellToken: 'bc1qqqqqqqqqqqqqqqqqqqqqqqqqqqqqqqqmql8k8', // native BTC
    buyToken: '0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913', // USDC on Base
    sellAmount: '1000000', // 0.01 BTC (8 decimals)
    originAddress: '$USER_BITCOIN_ADDRESS', // Bitcoin address that holds the BTC
    destinationAddress: '$USER_EVM_ADDRESS', // Base address that receives the USDC
    sortQuotesBy: 'price',
    maxNumQuotes: '3',
});

const headers = {
    '0x-api-key': '[api-key]', // Get your live API key from the 0x Dashboard (https://dashboard.0x.org/apps)
};

const response = await fetch('https://api.0x.org/cross-chain/quotes?' + quotesParams.toString(), { headers });
const quoteResponse = await response.json();
```

Check these points before you use the quote:

- Do not send `feeBps`, `feeRecipient`, or `feeToken`. The API returns HTTP 400 with the reason `Fee collection is not supported when origin chain is Bitcoin`.
- `allowanceTarget` is `null`. Bitcoin has no approval step and no wrap step.

### 2. Sign the PSBT

Sign the PSBT from the quote you picked with the key for `originAddress`. Follow these rules:

- Do not add, remove, or reorder inputs or outputs.
- Do not build a new transaction from the quote. The PSBT already pays the miner fee.

```typescript
import { Psbt } from 'bitcoinjs-lib';

const quote = quoteResponse.quotes[0];
const psbt = Psbt.fromHex(quote.transaction.details.psbt.replace(/^0x/, ''));

// `keyPair` signs for $USER_BITCOIN_ADDRESS.
// Load it from your wallet or key store. Do not put a private key in your code.
psbt.signAllInputs(keyPair);
psbt.finalizeAllInputs();

const tx = psbt.extractTransaction();
const rawTx = tx.toHex();
const txid = tx.getId();
```

If a wallet app signs for your user, pass it the same PSBT hex.

### 3. Broadcast the transaction

Send `rawTx` to the Bitcoin network through your own node or a broadcast service.

### 4. Monitor the cross chain execution

Poll `/status` with `originChain` set to `bitcoin`, `originTxHash` set to the txid, and the `quoteId`.

```typescript
const statusParams = new URLSearchParams({
    originChain: 'bitcoin',
    originTxHash: txid, // 64 hex characters, with or without a 0x prefix
    quoteId: quoteResponse.quotes[0].quoteId,
});

const statusResponse = await fetch('https://api.0x.org/cross-chain/status?' + statusParams.toString(), { headers });

console.log(await statusResponse.json());
```

For the status lifecycle and failure handling, see [Tracking Transaction Status](/cross-chain/cross-chain-api/key-concepts/tracking-transaction-status).
